## Overview

**La Letizia** is a premium frontend web application for an architectural nocturnal sanctuary located in Ballygunge, Kolkata. Built with **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS**, the experience is anchored in the design aesthetic of **Exaggerated Minimalism**: an obsidian palette, illuminated gold and champagne metallic accents, 900-weight editorial serif typography, sharp brutalist geometric borders (`0px`), and instant inversion interactions.

All visual assets are sourced exclusively from authentic high-resolution photographs of the physical Kolkata venue (the cascading indoor waterfall atrium, honeycomb gaming salon with championship foosball, botanical rooftop balcony, and suspended nautical rope Edison mirror bar) and 12 original scanned physical menu cards.

---

## Core Features & Architecture

### 1. 00 // Sensory Prologue & Bespoke Honeycomb Loader
- **Kinetic Typography Streams:** High-velocity angled marquees streaming across 5 geometric vectors that magnetically converge into the central brand title.
- **Bespoke Concentric Loader:** Concentric animated gold hexagonal tracing, counter-rotating silver geometric alignment rings, a 45° brutalist core diamond, and real-time spatial calibration tickers.
- **Architectural Shutter Split:** Top and bottom obsidian panels slide apart vertically with a luminous gold laser dividing line as the site scales smoothly into view.

### 2. 01 // Spatial Hero & Brand Identity
- Colossal editorial serif headline (`LA LETIZIA`) paired with illuminated gold outlines and real architectural plate showcase windows.
- Instant inversion action buttons for Direct Online Ordering, VIP Table Reservation, and Tasting Menu navigation.

### 3. 02 // The Experience (Spatial Architecture)
- Tabular architectural zone switcher featuring the **Waterfall Atrium**, **Honeycomb Lounge**, **Botanical Balcony**, and **Mirror Bar**.

### 4. 03 // Find Your Corner (11 Authentic Photographs)
- Asymmetrical photographic gallery categorized by spatial ambiance with sharp plate inspection modals, spatial attributes, and Kolkata landmark metadata.

### 5. 04 // Gastronomic Archive & Direct Ordering
- **Interactive Culinary Vault:** Marquee accordion portal unveiling 120+ authentic dishes across 9 cuisine categories (Kebabs, Continental, Burgers, Chinese, Indian Mains, Mocktails, Desserts, and Royal Sheesha).
- **Direct Online Ordering:** Inline `[ + ORDER ]` and quantity controls `[ - ] (qty) [ + ]` on every dish card.
- **Interactive Table Tasting Board:** Floating tasting dock with direct order synchronization and reservation pass attachment.
- **12 Original Menu Cards Lightbox:** Full-resolution physical menu card viewer with keyboard navigation (`←`/`→`/`Esc`) and full-res download.

### 6. 05 // Direct Online Ordering & Digital Kitchen Token (KOT)
- **Direct Order Modal:** Order mode selection (Counter Takeaway vs. Dine-in Table Pre-order), customer protocol form, itemized breakdown, and automated GST calculation.
- **Live Digital Kitchen Token:** Issues an official order token (`#LL-ORD-xxx`) with pickup collection instructions, print pass functionality, and **1-Click WhatsApp Concierge Dispatch** pre-formatting the full order to `+91 90518 77777`.
- **Persistent Floating Order Dock:** Floating brutalist bag at the bottom right displaying active item counts and totals.

### 7. 06 // VIP Table Inquiry Protocol
- Form validation preventing past-date reservations, real-time party size selection, corner preference synchronization, and simulated VIP Boarding Pass generation (`#LL-xxxx`).

### 8. 07 // Destination & Concierge
- Real illuminated exterior facade photograph, exact landmark address opposite Quest Mall Gate 5, operating hours, and verified Google Maps destination links.

## Getting Started

### Prerequisites
- Node.js (v18.17.0 or later)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/subhranil1234/La-letizia.git

# Navigate into the project directory
cd La-letizia

# Install dependencies
npm install

# Run the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Compile and optimize for production
npm run build

# Start the production server
npm run start
```
